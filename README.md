# Bus Coin — Busmac Viajes App

Prototipo de una app para pasajeros de micros de larga distancia (Busmac Viajes y Turismo). Los pasajeros eligen un perfil (estudiantes, jubilados, familia, pareja) y acceden a juegos, trivia, ranking del grupo y una tienda de fichas para desbloquear extras durante el viaje.

## Contenido

- `index.html` — prototipo autocontenido (HTML + CSS + JS) que simula la app dentro de un mockup de celular. Se abre directo en el navegador, sin build ni dependencias.

## Cómo verlo

Abrí `index.html` en cualquier navegador.
